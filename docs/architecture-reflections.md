## The Core Narrative

I built a **Hermes Agentic Firm** — four autonomous AI agents (eventually) running 24/7 on a VPS, each with their own identity, Telegram bot, and domain. This is not a demo. This is production.

The story worth telling:

---

## 1. Why Agents ≠ Chatbots

The market conflates the two:
- **Chatbots** wait for prompts. They're reactive.
- **Agents** act autonomously. They have schedules, identities, and domains.

My CTO doesn't wait for me to ask "what's in my repos?" — it scans them every Monday, Wednesday, and Friday at 2 AM Mexico City time and delivers findings to my phone before I wake up.

**Key insight:** The difference between "AI that answers questions" and "AI that does work" is the cron schedule.

---

## 2. The Multi-Instance Pattern

Most agent setups run one instance. I run **four independent instances** on the same VPS, each with:
- Its own Telegram bot (isolated — compromise of one doesn't affect others)
- Its own OpenRouter API key (separate billing, separate rate limits)
- Its own memory profile (CEO remembers preferences; CTO is stateless by design)
- Its own identity and "personality"

**Why Mad Men personas work:**
- Don Draper (CEO) thinks in strategy and vision
- Peggy Olson (CTO) writes the code and reviews it
- Don Draper (CMO) tells the story
- TBD (CFO) watches the numbers

These aren't gimmicks — they're **compartmentalization of concerns**. Each agent has a clear domain boundary, which means no cross-contamination of context, no conflicting priorities, and crystal-clear failure domains.

---

## 3. Cost Optimization as Architecture

Total cost for 4 agents: **~$0.60/month**.

How:
- **Zero-token data pipelines:** Scripts collect structured data before the LLM touches it. The CTO's night scan walks the GitHub API tree in pure Python — the LLM only reasons about pre-digested JSON.
- **no_agent mode:** Routine reports are generated by Python scripts. Zero LLM cost. Silent when nothing new.
- **Model discipline:** DeepSeek V4 Flash for routine work. Upgrade only when the task genuinely requires reasoning.
- **Frequency reduction:** 3x/week instead of daily = 60% fewer runs.

**The lesson:** AI agents don't have to be expensive. The architecture determines the cost.

---

## 4. Telegram as the Universal Interface

Each agent delivers to its own Telegram bot:
- CEO → personal channel (daily metrics, planning confirmations)
- CTO → technical channel (code reviews, research briefs)
- CMO → brand channel (content drafts, engagement metrics)

**Why Telegram:**
- Push notifications (I don't check dashboards)
- Media-rich (code blocks, images, voice memos)
- Async by design (I read when I wake up)
- Dual bots cost nothing extra

The mobile-first delivery pattern means the agents work while I sleep, and I consume their output in the morning like email.

---

## 5. The Skill Economy

Skills are reusable modules that give agents capabilities:
- `google-workspace` → calendar read/write
- `github-code-review` → repo analysis
- Future: `linkedin-publisher`, `twitter-engagement`

**Key insight:** The agent platform's value is proportional to its skill ecosystem. Hermes' skill standard (agentskills.io) means skills written by anyone can be loaded by any agent.
